SITE POLICY

Privacy Policy

Last updated: 14 October 2026

This policy describes data handling for the GitHub Pages edition of MicrobeQuest: The Outbreak Files, an educational microbiology game. The GitHub Pages edition runs in your browser and does not send registration details or learning events to the project owner.

Registration and consent: the form asks for your name, email, programme, year of study, and optionally your institution. In this GitHub Pages edition, these details and progress are saved only in your browser using local storage. The project owner cannot access them through this static site. Do not submit health information, patient information, or confidential details.

Information collected

The browser stores the registration details you submit and basic learning events, including investigation starts, answer outcomes, hint use, score, stage number, restarts and completion. This information stays in that browser unless you clear site data or remove it yourself. It is not transmitted to the project owner by this static GitHub Pages site.

The local records are intended to help you retain participation and progress on the same device. Because this version has no connected database, the project owner does not receive registrations or aggregate analytics from it. It is not a clinical system and the data should not be used to make healthcare decisions.

Hosting and technical information

The static edition is hosted by GitHub Pages. GitHub may process technical information such as request data, IP address, browser details or security logs to deliver and protect the service. The site owner does not control all hosting-level processing. Consult GitHub’s current privacy information for details of its practices.

Third-party fonts

The site currently requests fonts from Google Fonts. When a browser loads those fonts, the request is made to Google’s servers and may expose technical connection information to that provider. The fonts can be self-hosted in a future update to reduce this external dependency.

Children and sensitive information

This is an educational simulation, not a place to submit personal, confidential, patient or other sensitive information. Do not enter real patient data.

Retention and deletion requests

Registration and learning-event records are stored in your browser’s local storage, not in a project database. To clear them, use your browser’s site-data controls. The project owner cannot retrieve these local records to correct or delete them. Hosting logs may be retained by GitHub according to its own policies.

For questions about registration data, contact the student project owner at anubhutiworkk@gmail.com.

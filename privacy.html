Privacy Policy

Last updated: 17 October 2026

This policy explains the limited data handling associated with MicrobeQuest, a student-built educational website hosted as a static site. The site is intended for learning microbiology through teaching cases. It does not currently offer user accounts, contact forms, payments, or a server-side database.

1. Information stored in your browser

The current prototype uses your browser's local storage to remember a case score and completion status. This information stays in that browser on that device unless you clear the site's data. It is not an account, is not synced between devices, and is not sent to MicrobeQuest through the site's application code.

2. Hosting and technical information

The website is published through GitHub Pages. The hosting provider may process technical information such as IP address, browser details, request logs, and security information as part of delivering and protecting the website. That processing is governed by the provider's own policies and practices. MicrobeQuest does not control the hosting provider's infrastructure or logs.

3. Third-party services

The website's code and files are stored in a GitHub repository. Links to GitHub open an external service governed by its own policies. The site's styling requests fonts from Google Fonts; when those font requests are enabled, your browser connects to Google's servers to retrieve them. You can block external requests through browser or network settings, although typography may change.

4. Cookies, analytics, and advertising

The current application code does not intentionally set advertising cookies, run analytics, or display targeted advertising. Browser local storage is used for progress as described above. Hosting infrastructure or third-party services may use their own technical mechanisms under their own policies.

5. Student use

Do not submit private, confidential, or identifying information through public issues or other external services. If the site later adds accounts, forms, analytics, embedded content, or other data collection, this policy must be reviewed and updated before that feature is launched.

6. Your choices

You can clear MicrobeQuest's local storage through your browser's site-data settings to remove locally saved progress. You can also use browser settings or extensions to restrict external requests. Restricting local storage means the site may no longer remember your progress.

7. Policy changes and contact

This policy may be updated when the site's features or hosting arrangements change. For questions or to report a privacy concern, use the project's GitHub Issues page. Do not post personal or sensitive information in a public issue.

Important: This is a plain-language draft for the current prototype, not legal advice. Review it against the actual deployment, third-party requests, and applicable legal requirements before public launch.

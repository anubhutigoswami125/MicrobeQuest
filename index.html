About This Project

MicrobeQuest: The Outbreak Files is an academic assignment and a personal passion project exploring agentic AI coding, interactive scientific storytelling, and microbiology education. It combines a fictional teaching simulation with evidence-led investigative gameplay and links to primary public-health reading.
